# Rutyro portfolio site

Portfolio page for Rutyro's open-source projects:

- **SystemCompass** - Windows startup audit with verified, reversible changes.
- **claude-code-bridge** - MCP bridge between coding-agent sessions over SSH.

Plain HTML and CSS, no build step, no external dependencies.

- Edit `index.html` and `styles.css`, then commit and push to `main`.
- Screenshots in `assets/` use fictional demo data.
- GitHub Pages serves the repository root.
